## 🪜Procedures:

### Module 1: W3-PM1: Password Cracking with JTR

First the JTR or John The Ripper Password cracker is downloaded from the source. Then Johnny is installed and the path of the John.exe file is pasted in the settings of the Johnny. Configuration is done.
<img width="863" height="686" alt="Screenshot 2026-08-25 214628" src="https://github.com/user-attachments/assets/e9c45ed4-9061-4512-b5d1-d0bba8efb927" />


Next, the password protected locked PDF File is downloaded. After that we go to " https://www.onlinehashcrack.com/ " website and from Security Resources option, we choose PDF Hash Extractor.
<img width="1445" height="868" alt="Screenshot 2026-08-25 215051" src="https://github.com/user-attachments/assets/07831ca2-3b7c-499b-b8c8-97b916ee822c" />
<img width="1688" height="756" alt="Screenshot 2026-08-25 215602" src="https://github.com/user-attachments/assets/99180b7e-0689-408e-81a9-946bf18e0d59" />


Then the PDF file is uploaded in the onlinehashcrack website. The website will then provide the Hash value of the PDF file.
The given Hash value is copied and then pasted and saved on a text document. 

A hash value is a fixed-length string of numbers and letters generated by running data (like a file, password, or message) through a mathematical algorithm called a hash function. It acts as a unique digital fingerprint; changing even a single character in the input data creates a completely different output.


Now, in the Johnny tool, Passwords ➡️ Open Password File ➡️ PASSWD format ➡️ choose the text document file containing Hash value

<img width="1027" height="762" alt="Screenshot 2026-08-25 220359" src="https://github.com/user-attachments/assets/cc67e403-db0c-415a-9b12-ef50977dbf38" />



Next,
Start New Attack ➡️ The tool has cracked the Password which is good-luck
